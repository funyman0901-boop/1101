# Габариты деталей — КОМПАС-3D v24

**Версия 1.3: обработка выбранной папки и всех вложенных папок. Открытая сборка не требуется.**

## Скачать

[Скачать утилиту 1.3 для Windows x64](https://github.com/funyman0901-boop/1101/raw/refs/heads/main/downloads/KompasDimensions24-1.3-folder.zip)

Python устанавливать не требуется. Нужен установленный КОМПАС-3D v24.

## Как пользоваться

1. Распакуйте архив и запустите `KompasDimensions24.exe`.
2. Нажмите **«Выбрать папку...»** и укажите папку с деталями `.m3d`.
3. Оставьте **«Габариты готовой модели»**.
4. Нажмите **«Записать свойства + Excel»**.

Утилита ищет `.m3d` и `.M3D` во вложенных папках, открывает каждый файл в КОМПАС, рассчитывает размеры, записывает свойства «Длина», «Ширина», «Высота» и сохраняет файл. КОМПАС запускается автоматически, если не найден работающий экземпляр. Перед записью закройте отдельные окна деталей и сохраните изменения. Для первого запуска используйте копию папки.

Кнопка **«Сформировать Excel»** выполняет измерение без записи свойств.

Если «Раздел спецификации» не заполнен, модель обрабатывается как обычная деталь. В версии 1.2 исправлена ошибка чтения `(False, None, False)` для незаданного раздела. Явные исключения сохранены.

## Новое в 1.3

- Обрабатываются основное и остальные исполнения каждого файла.
- Геометрия каждого исполнения переключается и перестраивается перед измерением.
- Размеры записываются в `IPropertyKeeper` соответствующего `IEmbodiment`.
- В Excel и журнале есть колонка «Исполнение».
- Перед сохранением восстанавливается исходное активное исполнение.
- Проверяется отсутствие перезаписи соседних исполнений и изменения исключённых исполнений по наследованию.
- При ошибке одного исполнения файл целиком не сохраняется; остальные файлы продолжают обрабатываться.
- Убран обязательный вызов `IPart7.Update()`, вызывавший ошибку «Не обновлены свойства верхнего компонента». Чтение и проверка свойств после сохранения остаются обязательными.

## Что сохраняется

- Excel с числами без формул: размеры, журнал, итоги.
- Общие определения трёх свойств с одинаковыми ID во всех моделях.
- Резервная копия каждой детали перед записью.
- JSON-журнал; прогресс обработки `[номер/всего]`.

Результаты по умолчанию находятся в «Документы / Габариты КОМПАС». Папки отчётов и резервных копий исключаются из поиска. Ошибка одного файла не останавливает остальные.

Стандартные компоненты и раздел **«Прочие изделия»** исключаются по данным самого файла, без проверки его имени. Файлы `.a3d` не обрабатываются.

## Способы измерения

- Габариты готовой модели: длина ≥ ширина ≥ высота, мм, по осям исходного файла.
- Заготовка: вычисленные значения переменных `BLANK_L`, `BLANK_W`, `BLANK_H`, заданные в мм. Произвольные эскизы и операции автоматически не распознаются.

Исполнения обрабатываются отдельно с собственными значениями размеров. Поворот геометрии внутри детали может увеличить осевой габарит.
