# Габариты деталей — КОМПАС-3D v24

Утилита для Windows x64: измерение уникальных деталей открытой сборки, обход вложенных сборок, запись числовых свойств и отчёт Excel без формул.

## Скачать

[Скачать KompasDimensions24.zip](https://github.com/funyman0901-boop/1101/raw/refs/heads/main/downloads/KompasDimensions24.zip)

Python устанавливать не требуется. Распакуйте архив и запустите `KompasDimensions24.exe`. Откройте и сохраните сборку в КОМПАС перед обработкой.

## Возможности

- Габариты исходных файлов `.m3d`: длина ≥ ширина ≥ высота, мм.
- Отдельный режим заготовки по переменным `BLANK_L`, `BLANK_W`, `BLANK_H`.
- Исключение стандартных компонентов и раздела «Прочие изделия» по метаданным КОМПАС.
- Кнопки «Сформировать Excel» и «Записать свойства + Excel».
- Общие определения свойств «Длина», «Ширина», «Высота»; резервные копии перед записью.
- Журнал ошибок и пропусков.

## Проверка и ограничения

Сборка: Python 3.11.9, PyInstaller 6.16.0, Windows x64 через Wine. Проверены запуск упакованного окна, экспорт Excel и семь тестов логики. **Подключение COM, измерение и сохранение на реальном КОМПАС-3D v24 ещё не проверены. Первый запуск с записью выполняйте на копии сборки.**

Локальные детали без отдельного `.m3d` и файлы с несколькими исполнениями пропускаются. Габариты измеряются по осям исходной детали; поворот геометрии внутри файла может увеличить результат. Автоматическое распознавание произвольного эскиза заготовки не реализовано.
